Python Basics · Part 1

Variables & Data Types

int — Integer
age = 22
Whole numbers — no decimal point. Used for counts, indices, IDs.
float — Decimal
score = 92.5
Numbers with decimals. Used for prices, percentages, measurements.
str — String
name = "Devansh"
Text in quotes. Used for names, labels, categories.
bool — Boolean
is_active = True
True or False only. Used for flags, conditions, filters.
# Checking data types
print(type(age)) # <class 'int'>
print(type(score)) # <class 'float'>
print(type(name)) # <class 'str'>

# f-strings — clean way to mix text and variables
print(f"My name is {name} and I scored {score}%")

Python Basics · Part 2

Lists & Dictionaries

List → An ordered collection of items (like a column in a spreadsheet)
scores = [88, 92, 79, 95, 84]
print(scores[0]) # 88 (first item)
print(scores[-1]) # 84 (last item)
print(scores[1:3]) # [92, 79]
print(len(scores)) # 5
scores.append(91) # add item
Dictionary → Key-value pairs (like a row in a spreadsheet with column names)
student = {"name": "Alice", "age": 21, "score": 92.5}
print(student["name"]) # Alice
student["grade"] = "A" # add new key
print(student.keys()) # dict_keys([name, age, score, grade])
List = Array-like
→ Becomes a NumPy array
→ Becomes a Pandas Series
Dict = Table-like
→ Becomes a Pandas DataFrame
Key Shortcut

Python Basics · Part 3

Loops & Conditions

for loop — repeat over a collection
scores = [88, 45, 92, 34, 77]

for score in scores:
  if score >= 60:
    print(f"{score} → ✅ Pass")
  else:
    print(f"{score} → ❌ Fail")

# 88 → ✅ Pass
# 45 → ❌ Fail ...
List Comprehension — Pythonic one-liner loops
# Traditional loop
passing = []
for s in scores:
  if s >= 60: passing.append(s)

# List comprehension — same result!
passing = [s for s in scores if s >= 60]

# Squaring each score
squared = [s**2 for s in scores]
Pro tip: In data science, you'll mostly use NumPy vectorised operations instead of loops — much faster!

Python Basics · Part 4

Writing Functions

Functions let you package reusable logic. In data science, you'll write functions to clean columns, transform features, and process entire datasets.

# Basic function
def greet(name):
  return f"Hello, {name}! Welcome to Data Science."

print(greet("Devansh"))

# Data science function with default argument
def calculate_grade(score, passing_mark=60):
  if score >= 90: return "A"
  elif score >= 75: return "B"
  elif score >= passing_mark: return "C"
  else: return "F"

scores = [88, 92, 45, 67]
grades = [calculate_grade(s) for s in scores]
print(grades) # ['B', 'A', 'F', 'C']
Anatomy of a Function
🔑 def keyword
📝 Function name
📥 Parameters (inputs)
⚙️ Body (logic)
📤 return value
Lambda Functions
# One-line function
double = lambda x: x * 2
print(double(5)) # 10
You'll use this a lot with Pandas .apply()
